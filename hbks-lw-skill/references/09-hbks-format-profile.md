## 3. 原创性声明 + 版权使用授权书（同在第 2 页，8/8）

- 两个标题均为 15 pt 黑体居中（个别 16 pt 加粗）。
- 正文宋体、1.5 倍行距、首行缩进约 2 字符（22–24 pt）；授权书正文含“河北科技师范学院有权保留……”。
- 签名栏两列：“论文作者（签名）：　　指导教师确认（签名）：”；日期行“年　月　日”为合法手写留白。
- **不得**把样本论文的签名/日期/个人信息迁入；未知签署日期不代填。

## 4. 摘要、ABSTRACT、目录

| 元素 | 格式 |
|---|---|
| “摘　　要”标题 | 15 pt 黑体居中（两字用两个全角空格补足四字宽） |
| 中文摘要正文 | 宋体 12 pt，首行缩进 2 字符，行距固定 20 pt 或 1.5 倍；约 3–5 句 |
| “关键词：” | 12 pt 黑体，无缩进，前缀“关键词：”，分号分隔 3–6 个 |
| “ABSTRACT”标题 | 15 pt 黑体居中（个别 18 pt） |
| 英文摘要正文 | Times New Roman 12 pt，首行缩进 2 字符 |
| “Key words：” | 12 pt 加粗，逗号/分号分隔，与中文一一对应 |
| “目　　录”标题 | 15 pt 黑体居中 |
| 目录本体 | Word 自动目录域（toc1/toc2/toc3 样式），带点线引导符和页码，显示 1–3 级；**目录从“第1章”起，不含摘要/ABSTRACT/目录本身** |

## 5. 标题层级（视觉格式 8/8 一致；样式名各异，以视觉为准）

| 层级 | 字体 | 字号 | 对齐 | 编号 |
|---|---|---|---|---|
| 章标题 | 黑体 | 15 pt（三号） | 居中 | `第X章　标题`（全角空格分隔） |
| 节标题 | 黑体 | 14 pt（四号） | 左对齐 | `X.X　标题` |
| 小节标题 | 黑体 | 13 pt | 左对齐 | `X.X.X　标题` |
| 不编号一级标题 | 黑体 | 15 pt | 居中 | 摘　　要 / ABSTRACT / 目　　录 / 结　　论 / 参考文献 / 致　　谢 / 附　　录 |

- 章标题用阿拉伯数字章号（“第1章”，非“第一章”）；`第X章` 与标题之间用全角空格。
- **结论不编号**（不写“第7章”），作为一级标题紧接第6章之后；8 篇中 7 篇设独立“结　　论”，1 篇（李子凡）未设单独结论。
- 部分论文未使用内置 Heading 样式而是用“Normal 15pt 黑体居中”直接排版，但**视觉结果与 Heading 1 相同**；本技能统一套 Heading 1/2/3 以便生成目录，属可接受的差异。

## 6. 正文段落

- 中文宋体、西文 Times New Roman、12 pt（小四），两端对齐。
- 首行缩进 2 字符（24 pt）；行距为**固定值 20 pt** 或 **1.5 倍**（两种都出现，全篇统一即可）。
- 段前段后 0 磅。

## 7. 图与表

- 图题注在**图下方**、表题注在**表上方**，均居中；格式 `图X.Y　题注` / `表X.Y　题注`（全角空格，无结尾句号），题注约 10.5 pt（五号）宋体。
- 表格一律三线表（顶线/栏目线/底线，无竖线）。
- 数据库字段表列方案**逐篇不同**（同一项目内必须统一）：
  - 4 列：列名 / 数据类型 / 长度 / 说明（焦佳铭）；字段名 / 数据类型 / 约束·默认值 / 字段说明（任畅通）
  - 5 列：字段名 / 数据类型 / 约束 / 默认值 / 说明（李东亮）
  - 6 列：字段名 / 描述 / 类型 / 长度 / 是否空 / 是否主键（戴江硕）；字段名称 / 类型 / 长度 / 字段说明 / 主键 / 默认值（金师杰、王博）
  - 7 列：编号 / 字段名 / 类型 / 长度 / 是否非空 / 是否主键 / 注释（孟凡宇）
- 结论：本技能默认 7 列三线表可接受；若模板/导师指定列方案，以指定为准，不为了套默认列而删掉真实约束信息。

## 8. 参考文献（GB/T 7714 顺序编码制，8/8 一致）

- “参考文献”一级标题 15 pt 黑体居中；条目 10.5 pt（五号）宋体、悬挂缩进、按正文首次引用顺序编号 `[1] [2] …`。
- 出现过的文献类型：`[J]` 期刊、`[M]` 专著、`[D]` 学位论文、`[EB/OL]` 电子资源、`[N]` 报纸、`[R/OL]` 报告、`[S/OL]` 标准；部分含 DOI。
- 中文作者 >3 人列前 3 人加“等”；英文用大写姓氏或“et al.”，同一篇内风格统一。

## 10. 本技能默认值 vs 实证的结论

1. 页面、页边距、页眉页脚、字体字号、标题层级、三线表、GB/T 7714——技能默认值与 8 篇实证**高度一致**，可直接沿用。
2. 需要在写作/生成时显式保证的：①正文页眉固定“河北科技师范学院学士学位论文”；②结　　论/致　　谢/附　　录等两字标题用两个全角空格补足四字宽；③前置页罗马、正文阿拉伯页码；④目录不含摘要/ABSTRACT/目录；⑤字段表列方案同一项目统一。
3. 文献条目格式见 `02-writing-standards.md` §12；前置页模板与分页见 `08-template-and-pagination.md`。
