# 质量闸门与交付报告

> 原则：**闸门不过，不声称完成**。每次修改 `manuscript.md` 或图片后，至少重跑内容闸门；每次重新生成 docx 后，重跑 docx 闸门与 PDF 版面核对。

## 闸门 0：输入与场景

- [ ] 已拿到项目源码/仓库路径，能读到 Controller/Service/Mapper、实体、SQL、前端页面。
- [ ] 已拿到作者信息（姓名、学号、院系、专业、指导教师、题目）。
- [ ] 已确认学校/学院模板要求（有模板则先逆向页边距、字体、封面、声明、参考文献格式）。
- [ ] 已确认 AI 使用场景：若学校明令禁止 AI 参与，**停止**并告知本规范不适用；若允许但需披露，交付时提醒披露义务。
- [ ] 已明确缺证清单：无截图的界面、无日志的测试结论、无来源的文献，全部登记，不编造。

**通过标准**：`paper-context/project-evidence.md` 存在；缺证清单逐条列出；作者信息无空缺。

## 闸门 1：大纲

- [ ] 六章齐全：绪论、相关技术、需求分析、系统设计、系统实现、系统测试。
- [ ] 第 3 章含 3.1.1/3.1.2/3.1.3、3.2.1/3.2.2/3.2.3。
- [ ] 第 4 章含 4.1、4.2、4.3，且 4.3.1/4.3.2/4.3.3 齐全。
- [ ] 第 6 章含 6.1–6.4。
- [ ] 图表落位表已填：图3.1/3.2、图4.1–4.7、图4.8 起每个实体的属性图、第 5 章截图清单。
- [ ] 第 2 章技术清单只含项目真实使用的技术；第 5 章模块与图4.6、正文功能一一对应。

**命令**：

```bash
python <skill>/scripts/check_manuscript.py manuscript.md --draft
```

此时正文可能还没写满，结构类错误必须先清零，单章字数警告可暂时保留。**分章写作阶段**用 `--draft`；成稿检查**不能**加 `--draft`，总字数不在 12000–16000 会直接阻断。

## 闸门 2：内容、字数与证据

逐章写作时每完成一章跑一次：

```bash
python <skill>/scripts/check_manuscript.py manuscript.md --draft --json output/content-check.json --out output/content-check.md
```

成稿检查（必须执行，不带 `--draft`）：

```bash
python <skill>/scripts/check_manuscript.py manuscript.md --json output/content-check.json --out output/content-check.md
```

必须清零（ERROR）：

- [ ] **正文总字数（第1章–结论）不在 12000–16000 字闭区间**（多一个字少一个字都不行）。
- [ ] 缺少一级标题/必备小节。
- [ ] 图/表编号不连续、正文引用不存在、图/表没有引导句。
- [ ] **实体属性图缺失**：`entity-attributes.json` 中的每个实体都必须有对应题注的图。
- [ ] 字段表“注释”超过 4 个汉字。
- [ ] 正文出现“待补充/待完善/TBD/初稿/根据源码/从源码/源码文件”等未完成或过程措辞。
- [ ] 正文引用 [n] 在文末没有条目。
- [ ] 重复标点（“。。”“，，”）。

可保留但必须逐条判断（WARN）：

- 单章字数低于/超出建议预算（总字数仍必须落在硬性区间）；
- 第 5 章有截图占位（提交前必须清零）；
- 参考文献少于 10 条；
- 匿名引用、模板过渡词、超长句、句长节奏平；
- 术语混用；
- 英文摘要疑似缩水。

**通过标准**：ERROR=0，且 `stats.word_range_ok = true`；WARN 每条都有处理记录（改掉或说明为什么保留）。Word 的“全文统计”含封面/目录/摘要/参考文献等，通常比正文多 1500–3000 字；默认红线指正文，学校若按全文统计卡字数要先确认口径。

## 闸门 3：图表

- [ ] 9 张标准图（图3.1–图4.7）全部生成 `.vsdx` + `.png`。
- [ ] **每个实体一张实体属性图**（图4.8 起，数量 = `entity-attributes.json` 中实体数），全部生成 `.vsdx` + `.png`。
- [ ] 所有图打开 PNG 逐张检查：文字不溢出、连线不穿字、标签不压框、无裁切。
- [ ] **除实体属性图外，所有连线只有水平/垂直段，没有一条斜线**；折线拐角为 90°。
- [ ] **实体属性图为中心辐射版式**：实体矩形居中、属性椭圆环绕、每条线都是实体→属性的单段直线（允许斜），没有折线总线、没有箭头。
- [ ] **箭头方向正确**：源→目标；流程图只有一个开始/结束，开始无入边、结束无出边，所有节点从开始可达，判断分支都标“是/否”。
- [ ] 图号与题注、正文引用一致；图前有“如图X.Y所示”，图后有分析。
- [ ] 图4.7 实体/联系名与 4.3.2 文字、4.3.3 表名一致。
- [ ] 图4.6 模块名与第 5 章小节一致。
- [ ] 第 5 章每节有截图或占位；占位在提交前全部替换。
- [ ] `paper-context/figure-registry.json` 状态已更新（`generated` / `inserted`）。

**命令**：

```bash
python <skill>/scripts/gen_figures.py --spec-dir specs --outdir figs
python <skill>/scripts/gen_figures.py --spec-dir specs --check
python <skill>/scripts/gen_entity_attributes.py --spec specs/entity-attributes.json --outdir figs
python <skill>/scripts/gen_entity_attributes.py --spec specs/entity-attributes.json --check
```

`gen_figures.py --check` 会自动报告：非实体属性图的斜线段（含斜的 `points`）、缺目标箭头、主流程顺序与箭头方向不一致（`from`/`to` 写反）、缺开始/结束、开始有入边、结束有出边、从开始不可达、无法到达结束、判断分支未标注。
`gen_entity_attributes.py --check` 会自动报告：实体属性图误用折线/箭头、属性超过 8 个、文字溢出。任何一条报告都必须先改规格再重生成。

## 闸门 4：降 AIGC（S1–S12）

按 `03-humanize-standards.md` 执行，顺序 A（语义层）→ B（句层）→ C（文档层），全文整体处理，不只改标红段。

- [ ] S1 模板链：连续 3 句内同类模板过渡词 ≤1；“综上所述/总而言之”每千字 ≤1。
- [ ] S2 空壳句头：零信息“随着…/在…背景下/众所周知”段首句 = 0。
- [ ] S3 超长句：单句 ≤40 字；≥30 字句有内部停顿。
- [ ] S4 句长节奏：无连续 3 句长度相近；有长短交错。
- [ ] S5 真实锚点：信息段 ≥1 处不可预测细节；缺素材处登记外部缺证清单、成品不带待补充标记且全文无编造。
- [ ] S6 引用具名：无“有研究指出/研究表明/据报道”式匿名引用。
- [ ] S7 句式多样但有界：每约 500 字 ≥1 处句式变化；无“人味表演”怪句；嗓音一致。
- [ ] S8 结构非全闭环：段落开头/收尾/长度不同构；“引入—展开—小结”闭环段占比明显下降。
- [ ] S9 无断层：全文整体处理；随机抽两段风格一致；不只改标红段。
- [ ] S10 忠实性：事实、数字、术语、引文零走样；无新增内容。
- [ ] S11 披露义务：已提醒用户场景要求；需要时给出披露模板。
- [ ] S12 免责表述：无“保证通过/100% 人类”表述。

**机械自检命令**（覆盖 S1–S4 的一部分）：

```bash
python <skill>/scripts/check_manuscript.py manuscript.md
```

输出中的“超长句/连续三句长度相近/模板过渡词/空壳句头/匿名引用”对应上表，按提示逐条处理。

**注意**：先降 AIGC，再跑查重（改写可能抬查重率）；复测留 ≥2–5 个百分点裕量；不针对单一检测器过拟合；不保证任何检测器放行。

## 闸门 5：docx 结构（提交版 + 可编辑版）

```bash
# 提交版：PNG 内嵌
python <skill>/scripts/build_docx.py manuscript.md --out output/论文_排版前.docx
python <skill>/scripts/paginate_tables.py output/论文_排版前.docx --out output/论文.docx
python <skill>/scripts/update_fields.py output/论文.docx --pdf output/论文.pdf
python <skill>/scripts/check_docx.py output/论文.docx --manuscript manuscript.md

# 可编辑版：第3–4章结构图原位替换为 VSDX OLE
python <skill>/scripts/embed_vsdx.py output/论文.docx --figs figs \
    --out output/论文_可编辑版.docx --pdf output/论文_可编辑版.pdf
python <skill>/scripts/check_docx.py output/论文_可编辑版.docx --manuscript manuscript.md
```

- [ ] 6 节；封面/声明无页码；摘要罗马；正文阿拉伯 1 起；正文页眉存在。
- [ ] 封面一页、声明授权同页、前置页无机器槽位/他人信息，签署留白符合模板。
- [ ] 当前文件 .layout.json 由 Word 重排生成且 SHA-256 匹配；缺失/过期/版面错误均阻断。
- [ ] 自动目录 TOC 域存在，更新后条目页码正确；不包含摘要/ABSTRACT/目录自身。
- [ ] 标题用 Heading 1/2/3；一级 13 个左右（摘要、ABSTRACT、目录、6 章、结论、参考文献、致谢、附录）。
- [ ] 三线表短表整表同页；超长表按真实分页拆同号续表，每段同页、完整表头、独立三线；拆表数据逐格核对一致。
- [ ] 提交版图片宽度 ≤15 cm；错误占位数量为0，缺图直接阻断。
- [ ] **可编辑版：VSDX OLE 数量 = 第3–4章结构图数量**；EMF 预览数量 ≥ OLE 数量（`check_docx.py` 自动核对）。
- [ ] 可编辑版中第5章截图仍为 PNG（它们没有 vsdx，不能替换）。
- [ ] 两版章节、图号、图位置、题注完全一致；可编辑版第3–4章结构图页为矢量，第5章截图仍可为位图。
- [ ] 无“待补充/TBD/根据源码”残留；文档属性作者为作者姓名。

## 闸门 6：PDF 版面

逐页翻 PDF（提交版与可编辑版各抽查一遍；或用 PyMuPDF 渲染成图抽查）：

- [ ] 目录页码与正文实际一致（抽查 ≥3 处）。
- [ ] 无异常空白页、无孤行、无图注孤悬页底。
- [ ] 图与引导句尽量同页；大图不撑页；截图清晰未变形。
- [ ] 可编辑版：第3–4章结构图页为矢量（绘图对象而非位图），中文字体正常、无缺字方框；第5章截图可为位图。
- [ ] 短表整表同页；全部续页均有“续表X.Y　原表名”、完整表头、独立三线，表段不跨页、行不截断。
- [ ] 页边距均匀、字体无乱码/方框。
- [ ] 参考文献、致谢、附录正常起页且内容完整。

## 交付报告（必附）

完成时输出以下五部分，不要只说“已完成”：

1. **产物**：提交版 docx/pdf、可编辑版 docx/pdf、`figs/*.vsdx`、`figs/*.png`；章节数、图表数、正文总字数（必须注明落在 12000–16000 的哪一段，并给出 `stats.word_range_ok=true`）、可编辑版 VSDX OLE 数量。
2. **闸门结果**：内容闸门 ERROR/WARN 数、docx 闸门结果、PDF 抽页结论；贴命令与关键输出。
3. **仍需人工确认**：缺证清单、待替换截图、参考文献待核对项、学校模板差异。
4. **披露提醒**：若场景要求披露 AI 辅助，给出 `03-humanize-standards.md` §7 模板并提醒作者填写工具/版本/范围。
5. **免责**：不构成任何检测器通过保证；检测是概率性、版本相关的；最终验收是作者可辩护。

## 红线速记

1. **正文总字数（第1章–结论）必须落在 12000–16000 字闭区间**；成稿检查不带 `--draft`，`stats.word_range_ok` 必须为 true。
2. **实体属性图必须覆盖 E-R 图中的每一个实体**，不是只画一张；图4.8 起连续编号。
3. **除实体属性图外，所有连线只能横平竖直**，允许 90° 折线，禁止斜线/斜箭头；实体属性图用中心辐射直线版式（允许斜直线、不加箭头）；箭头方向、起止节点、可达性、判断分支标注必须通过 `gen_figures.py --check`。
4. 学校/导师规则 > 本技能默认值。
5. 不编造功能、字段、接口、测试结果、截图、文献、数据、学校规定；缺失就列缺口。
6. 第 5 章不放测试，第 6 章不放功能截图；无独立结论要求则不设第 7 章。
7. 正文禁止过程措辞与证据语言；图表先引导后出现。
8. 降 AIGC 不虚构、不隐瞒、不保证过检、不针对单检测器过拟合。
9. docx 变更后必须重跑闸门；闸门不过不得声称完成。
